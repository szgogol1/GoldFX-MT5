================================================================================
GoldFX — 本机安装（压缩包下不了时用这个）
================================================================================

重要：云端 Agent 无法直接写入你电脑的 D 盘。
下面三种办法任选一种。

--------------------------------------------------------------------------------
办法 A：网页下载安装包（优先试）
--------------------------------------------------------------------------------
1. 用浏览器打开（建议 Chrome）：
   https://cursor.com/agents/bc-5179bc7e-0776-43a8-a05d-31ebb9bf374e

2. 页面右侧 / 下方找到 Artifacts（制品）：
   - GoldFX_MT5_安装包.zip
   - 或 00xauusd_MT5.zip

3. 点下载 → 保存到 D:\

4. 解压：
   右键 zip → 解压到 D:\00xauusd\
   最终应有：D:\00xauusd\Experts\
            D:\00xauusd\Include\
            D:\00xauusd\install_to_MT5.bat

5. 双击 D:\00xauusd\install_to_MT5.bat
   粘贴 MT5 的 MQL5 路径后回车。

--------------------------------------------------------------------------------
办法 B：不用 zip，从 Cursor 文件树手动拷（下不了压缩包时）
--------------------------------------------------------------------------------
1. 打开上面同一个 Agent 网页
2. 左侧文件树打开文件夹：
     Experts\GoldFX_Intraday\
     Include\GoldFX\
     Presets\
3. 在本机新建：
     D:\00xauusd\Experts\GoldFX_Intraday\
     D:\00xauusd\Include\GoldFX\
     D:\00xauusd\Presets\
4. 逐个打开源文件 → 全选复制 → 粘贴保存到对应本地路径
   （至少需要 GoldFX_Intraday.mq5 + Include\GoldFX 下全部 .mqh）

5. MT5：文件 → 打开数据文件夹 → MQL5
   把上面三个文件夹分别拷进：
     MQL5\Experts\GoldFX_Intraday\
     MQL5\Include\GoldFX\
     MQL5\Presets\

6. MetaEditor 打开 GoldFX_Intraday.mq5 → F7 编译

--------------------------------------------------------------------------------
办法 C：本机 Cursor 桌面版直接打开仓库文件夹
--------------------------------------------------------------------------------
1. 安装/打开 Cursor 桌面客户端并登录同一账号
2. 若能同步/打开该 Agent 工程，在资源管理器中把
   Experts、Include、Presets 复制到 D:\00xauusd\
3. 再按办法 B 第 5–6 步装进 MT5

--------------------------------------------------------------------------------
装进 MT5 后检查
--------------------------------------------------------------------------------
- 导航器出现 Experts → GoldFX_Intraday
- 拖到 XAUUSD M5
- 勾选「允许算法交易」
- 可先 InpAllowTrade=false 只观察
